Preserve existing asset paths when maintaining this collection. Record supplier URL, retrieval date, model and document revision when adding or replacing a document. Existing research can be stale; filenames alone do not establish document identity or current specifications. Third-party documents and images retain their respective owners' rights.

Document identity review: the classic² and touring² single manual files currently have identical Git blob hashes. Verify against the supplier before treating the touring manual as model-specific. The original files are retained pending that review.
